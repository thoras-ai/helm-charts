{{- if not .Values.consoleApi.auth.adminSalt }}
  consoleApi.auth.adminSalt is unset, so the console falls back to a salt shared

  from the salt and the password together, so changing either signs everyone out.

{{- if include "thoras-console.bundledDatabaseEnabled" . }}

Database: BUNDLED -- EVALUATION ONLY
  No backups, no point-in-time recovery, no high availability, one replica.
  Its volume is DELETED with the release: `helm uninstall`, or switching to
  externalDatabase, destroys this data irrecoverably. Take a dump first if you
  care about it:
    kubectl exec sts/thoras-console-db -n {{ .Release.Namespace }} -- \
      pg_dump -U postgres {{ .Values.bundledDatabase.databaseName }} > console-backup.sql
  For production, point externalDatabase at a managed database instead.
{{- else }}
